# Folio

A documentation framework: format definitions, standards, and reference
material that govern how documents are written across projects.

Companion to [carrel](https://github.com/dichodaemon/carrel) (agentic dev
container and OMP framework).

---

## Contents

| File | Description |
|---|---|
| `doc-definitions/` | Format and structural requirements for each document type (design notes, plans, design studies, briefs, cookbooks, READMEs). |
| `standards/` | Conventions governing documentation and OMP configuration practices. |
| `references/` | Factual reference material (OMP configuration, tool setup). |
| `docs/` | Folio's own workflow documents (design studies about the framework itself). |
| `.gitignore` | Excludes `.omp` (generated by carrel's setup). |

---

## Usage

### As a documentation framework

Read the doc-definition for the type of document you're writing before
starting:

| I'm writing a... | Read this first |
|---|---|
| Design note | `doc-definitions/design-note_definition.md` |
| Feature specification (deprecated) | `doc-definitions/spec-doc_definition.md` |
| Implementation plan | `doc-definitions/impl-plan_definition.md` |
| Design study | `doc-definitions/design-study_definition.md` |
| Brief | `doc-definitions/brief_definition.md` |
| Change review | `doc-definitions/review_definition.md` |
| Cookbook entry | `doc-definitions/cookbook_definition.md` |
| README | `doc-definitions/readme_definition.md` |

For directory structure, file naming, and placement rules, see
`standards/document-structure_standards.md`.

### OMP integration

Carrel's OMP framework reads folio's doc-definitions and standards from
the workspace mount at `/workspace/folio/`. The folio OMP target in
carrel (`carrel/targets/folio/`) assembles OMP config for working in
this repo:
```bash
cd ~/code/carrel/targets/folio
bash setup.sh ~/code/folio
```
